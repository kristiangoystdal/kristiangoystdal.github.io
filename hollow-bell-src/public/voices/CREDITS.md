# Voice credits

All voices were generated offline with [Piper](https://github.com/OHF-Voice/piper1-gpl) (GPL-3.0; the tool only,
not the generated audio) from these voice models (https://huggingface.co/rhasspy/piper-voices):

| Role | Model | Dataset and licence |
|---|---|---|
| Narrator | en_GB-cori-high | Cori, recordings from LibriVox: public domain |
| Mirela | en_GB-jenny_dioco-medium | "Jenny (Dioco)", https://github.com/dioco-group/jenny-tts-dataset (attribution) |
| Ashgrove, Harrow | en_GB-northern_english_male-medium | OpenSLR 83, https://www.openslr.org/83/ : CC BY-SA 4.0 |
| Quill, Vale, Matron Hale, Pip, Headmaster, and one more | en_GB-vctk-medium | CSTR VCTK Corpus, University of Edinburgh, https://datashare.ed.ac.uk/handle/10283/3443 : CC BY 4.0 |

Pitch, tempo, echo and tremble were changed with ffmpeg.
